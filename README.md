# SeniScan AI

SeniScan AI ialah prototaip pembelajaran Pendidikan Seni Visual berasaskan AI untuk membantu pengguna mengenal, memahami dan mengingati unsur seni serta prinsip rekaan melalui imej persekitaran harian.

## Konsep
📷 Imbas → 🤖 Kenal → 🎨 Faham → 🧠 Ingat

Projek sedang dibangunkan untuk analisis imej AI, nota pembelajaran dan pengalaman mesra telefon.
